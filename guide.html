使用教程

EndBox 是给《明日方舟：终末地》玩家用的 Windows 桌面工具箱。下面按模块讲怎么用；只想知道怎么装，看第一节就够。

01 · 安装与启动

EndBox 是便携程序，不需要安装器。下载 EndBox-1.1.0-win64.zip，解压到任意目录， 双击 EndBox.exe 就能用。程序不写注册表、不进系统目录；卸载时删掉整个文件夹即可。

首次运行

  1. 解压后得到 EndBox/ 文件夹：EndBox.exe + _internal/ 运行库。
  2. 双击 EndBox.exe；第一次启动会在同目录创建 userdata/。
  3. Windows 弹「已保护你的电脑」时点「更多信息 → 仍要运行」；也可以先运行包里的 1-Start EndBox (first run).bat。
  4. 要读游戏按键（运行提示条）时，如果游戏本身是管理员权限，EndBox 也用管理员启动。

别放在 C:\Program Files 这类只读目录；写不进去时程序会把数据退回 %APPDATA%\EndBox，能用，但不便携了。

数据目录

便携模式下所有可变数据都在软件同目录的 userdata/：

  • settings.json 普通设置主题 / 窗口 / HUD / 运行设置
  • secure.dat 登录信息Windows DPAPI 加密
  • logs/ 运行日志出问题先看这里
  • timeline.json 当前轴自动保存
  • timeline_library.json 轴库手动保存的轴
  • plugins/ 插件市场安装的插件

02 · 账号中心

没登录也能用全部功能：账号页会显示一份演示数据并明确标注。想显示自己的资料：

  • 官服：用森空岛 App 扫码。
  • B 服：用哔哩哔哩 App 扫码。

登录后能看到：玩家卡（昵称 / UID / 等级 / 服务器）、理智（当前 / 上限 / 恢复速度 / 满溢倒计时）、 规模统计、干员列表（等级、突破、潜能、职业、元素）、地区探索、通行证与每日任务、帝江号基建、每日签到。

森空岛和 B 站都是社区第三方接口，没有官方 API；读不到的项目会显示「—」，不编造数据。

03 · 技能轴

技能轴（排轴）把一套连招排成一条有序的轴，运行时提示条会告诉你下一步按什么。

基本操作

  1. 先选 4 名干员组成队伍，顺序就是 1–4 号位。
  2. 往轴里加步骤：战技 / 连携 / 终结 / 切换干员 / 重击 / 注释 / 换行 / 分段 / 反复。
  3. 步骤可以拖动排序、撤销重做；轴可以存进轴库，也能导出分享码。
  4. 顶部实时估算总耗时和技力消耗，用的是游戏数据里的技能时长。

分享码

点分享会生成一段可以直接粘贴的话，包含干员列表和分享码（EB2: 开头），点一次就能复制整段。

04 · 运行提示条

点「开始运行」后，屏幕上出现一条置顶的提示条（不抢焦点、点不到），显示当前步骤和下一步按键；主窗口默认最小化。

真实键位

操作按键
战技 1–4 号位1 2 3 4 短按
终结技 1–4 号位长按 1–4（阈值默认 280ms）
连携技E
切换干员F1 F2 F3 F4
重击左键，提示条只显示不抢按键

运行控制

按键作用
F8退出运行
F9回到第一段
F10整轴反复开关
F11回到反复起点
F6 / F7提示条变淡 / 变实

按对、按错

按对前进；按错会直接跳过这一步，不弹提示，被跳过的卡片标红并抖一下。 进入下一步时，新卡片上有白色圆圈收缩提示。默认整轴反复：跑完自动回开头继续，只有 F8 才退出。

运行设置里可以调「显示长度」（3–9 格）、长按阈值、提示条透明度和位置，也能改成不自动最小化主窗口。

05 · HUD 覆盖层

HUD 和排轴完全独立，只显示账号、电池、时钟，标题是 Windows 用户名。 Ctrl+Alt+H 开关；鼠标穿透、不抢焦点、不进任务栏，位置 / 缩放 / 透明度在 HUD 页调。

独占全屏游戏可能把 HUD 盖住，请用窗口化或无边框模式。

06 · 325 计算器

  • 求解：给数字串和目标，算出怎么凑到目标；区间 DP + 精确有理数，结果独立复算。
  • 随机：L1–L5 难度、可指定种子，支持积分 / 级数 / 行列式题型。

公式用 LaTeX 实时排版；历史与收藏各保留最近 100 条，可以导出 PNG。

07 · 插件市场

插件页分「已安装」和「市场」：按分类浏览、搜索、安装、更新、卸载。官方源随程序分发，也能自己加第三方源； 安装时先解压到临时目录、校验 sha256 再落盘，不执行市场里的代码。

第三方源的插件由你自己判断可信度；权限没声明的能力会被宿主拒绝。

08 · 版本更新

设置页「版本与更新」会同时查 GitHub Releases 和仓库里的 version.json， 有新版时能看到更新日志、打开发布页、忽略这个版本；没网或限流时安静跳过。

09 · 数据与隐私

EndBox 不联网做统计，不上传任何数据。登录信息用 Windows DPAPI 加密保存在本机，只有当前 Windows 用户能解密，不进日志也不随分享码发出。

游戏数据来自公开数据站快照；头像、技能图标与素材只在本机读取，不随程序分发、不入库。游戏内容版权归鹰角网络所有。

10 · 常见问题

  • 双击没反应 / 一闪而过先看 userdata/logs/endbox.log；多为解压不完整或杀毒拦截
  • 提示条按键没反应游戏是管理员权限时，EndBox 也要以管理员启动
  • 没有毛玻璃最大化时关闭；系统不支持时回退纯色，不影响功能
  • 怎么备份轴和设置复制整个 userdata/ 目录即可
  • 项目是什么许可MIT；游戏素材版权归鹰角网络
